### 👨‍💻 À propos

Je suis étudiant en **Master DataScale** à l'Université Paris-Saclay, spécialisé dans la conception d'architectures de données distribuées et scalables. Mon focus actuel est l'écosystème **AWS** pour construire des pipelines de données robustes et performants.

* 🔭 **Objectif :** Maîtriser l'automatisation des flux de données sur le Cloud.
* ⚡ **Intérêts :** Optimisation SQL, Big Data Processing (Spark), et architectures Serverless.
* 📫 **Contact :** [viaourimi@gmail.com](mailto:viaourimi@gmail.com)
